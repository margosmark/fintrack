Quick Start

Up and running in 60 seconds

Clone, install, run. No Docker, no databases to set up, no API keys required.

terminal 
# Clone the repository
git clone https://github.com/margosmark/fin_tracker.git
cd fin_tracker

# Install dependencies
pip install -r requirements.txt

# Initialize your database
python fin_tracker.py init

# Add your first transaction
python fin_tracker.py add "Coffee" 4.50 --cat food

# View your spending summary
python fin_tracker.py report --month
  1. Clone the repo

    Grab the source from GitHub and cd into the project directory.

  2. Install dependencies

    One pip install command pulls in everything you need. No virtual environment tricks required.

  3. Initialize your database

    Sets up a local SQLite database in your project folder. Takes less than a second.

  4. Start tracking

    Add transactions, set budgets, and generate reports from the command line.
