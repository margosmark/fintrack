fin_tracker Architecture

Python-based Personal Finance Tracker — System Architecture Overview

Frontend

  • • Web interface served via Flask/Django
  • • HTML templates with dynamic data
  • • Dashboard with transaction views
  • • Chart.js / data visualizations
  • • Responsive forms for data entry

Backend / API

  • • Python REST API (Flask or FastAPI)
  • • Business logic: budgets, analytics
  • • Transaction categorization engine
  • • Recurring transaction detection
  • • Report generation & exports

Data Layer

  • • SQLite (dev) / PostgreSQL (prod)
  • • SQLAlchemy / Django ORM models
  • • Alembic for schema migrations
  • • Accounts, transactions, categories
  • • Budget tracking & goals
