What shipped

Newest first, in plain language: every milestone number is mapped to what changes when you open the app. No commit hashes — if it does not affect you, it does not belong on this page.

TL;DR. The product went from “a tracker you can use” to “a tracker you can hand to your agent” this month: an MCP surface with scoped tokens and per-call receipts, import paths for seven brokerages, one-click export, 2FA and passkeys, an installable phone app, and a security review that found seven things and had them fixed.

This wave is the last mile: the landing story, a guided first run inside the demo, and three walkthroughs that teach the product instead of describing it.

This wave: what shipped and what it means for you
MilestoneWhat it means when you open the app
M89Launch story & guided first runYour first demo visit gets a four-stop tour (drawer → import → reports → help), Help gains three story-shaped walkthroughs — first import, first budget, “your agent did this” — and this changelog. Skip the tour and it stays skipped; a Take the tour button in Help brings it back.
M87Own-the-edge securityRegistering with an address that already exists answers exactly like a brand-new one, so nobody can probe who has an account here. Passkey sign-in counters hardened, and the API map, CORS and security headers tightened to run on a bare box.
M86Release hygieneA page that would load with two console errors fails the pull request instead of shipping; every smoke-test request now has a timeout, so a dead endpoint can never wedge a release.
M85Supply-chain & release gatesEvery automated action is pinned to an immutable commit, pasted credentials in new code fail the build, a post-deploy smoke battery exercises the real origin on demand, and a red run on main is impossible to miss.

The agent wave

Shipped October 1, 2026

The agent wave: what shipped and what it means for you
MilestoneWhat it means when you open the app
M80MCP agent surfaceMint a scoped token in one call and point Claude, Cursor, or your own script at your ledger. A read-only token is read-only structurally — the write tools are removed from what it can even see — and every call lands in a receipt you can read and revoke.
M81Demo tokens + doc truth-upsThe demo can mint read-only tokens like anything else, and five guides were corrected where they described behaviour the product had already changed.
M82Brokerage imports & mobile fixesSeven broker activity exports are recognised — Questrade, Wealthsimple, IBKR, Fidelity, TD Direct Investing, RBC Direct Investing, NBDB — and seven mobile defects closed: tabs wrap instead of printing over each other, forms stack on small screens, touch targets stay at 44px, and Android font scaling stops pushing controls off-screen.
M79Open-banking seamA consent flow, a provider protocol, and the same staging your file imports use — so an accredited open-banking provider can plug in the day Canada’s framework is real. Until then the honest path stays the honest path: files, no scraping.
M83Security reviewA full pass over the running stack. Seven findings, every one tracked — two of them became the fixes below.
M84Cross-tenant credential leakA shared HTTP client inside the agent server could carry one account’s session cookie into another account’s request. Closed at the client, the cookie, and the session layers, with a probe that fails if it ever reopens.

Import, phone, and your own data

Shipped September 30, 2026

Import, phone and own-your-data wave: what shipped and what it means for you
MilestoneWhat it means when you open the app
M71The import barQIF joins OFX/QFX/CSV, a dry run survives you pressing Cancel, near-matches are flagged instead of silently merged, and there is a guide per Canadian bank telling you which export to pick and which date format will bite you.
M72Installable phone appAdd it to your home screen and it opens like an app: a real navigation drawer, 44px touch targets, pull-to-refresh that actually refetches, and an offline shell that never pretends to have your numbers.
M74Two-factor, passkeys, SSOTurn on an authenticator app, register a passkey so you stop typing the password, or plug in your own OpenID provider. Recovery codes come with it.
M75One-click exportSettings gives you a ZIP of plain CSV and JSON plus an OFX that round-trips back in, a scheduled export you can set and forget, and a published list of exactly what you get — the no-lock-in promise, with the file names on it.
M76YNAB importerBring your budget across: see the entire mapping — accounts, category tree, targets, every row — before a single write, with refused rows listed by number and reason instead of dropped.
M77Analytics depthA Sankey of where the money actually went, and total return (TWR/MWR) so your performance number is not flattered by the contributions you made along the way.
