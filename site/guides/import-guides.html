Import guides by bank

Where each Canadian institution keeps its export, which file to pick, and the date quirks that bite.

  1. Pick the format before you pick the file

    Three formats reach the Imports page. OFX and QFX are the same thing — QFX is just Quicken's name on OFX — and both are detected automatically with no column mapping, so grab whichever your bank offers. QIF is the older line-based format and is also detected on its own. CSV always needs its columns mapped once per institution; the wizard remembers the mapping, so it costs you one pass per bank and never again. Nothing is sent anywhere: the file is read by the server you host, which does not call out to a third party.

  2. Preview first, Confirm second

    Press Preview import and the whole file is parsed without writing a row. You get the column roles it used, every row's verdict — new, exact duplicate or near-duplicate — and the CAD amount produced from the cached exchange rate for that date. Confirm stores the batch for review; Cancel leaves nothing behind, so it is safe to preview a file you are not sure about.

  3. How duplicates are decided

    An exact duplicate matches something you already have on account, date, amount and description. A near-duplicate carries the same amount within three days with a payee close enough to be the same merchant — the preview names the matching row, how many days apart it is, and whether that row is already imported or still waiting in another import. Near-duplicates are imported and stay flagged in the batch: nothing is ever dropped for you. If you decide one is a repeat, discard the batch, or fix the row after you commit.

  4. Sample files, no real money in them

    Four synthetic statements, one per format, with invented merchants and amounts. Run one through Preview first if you want to see the verdicts before pointing the importer at a real export.

  5. Date formats are where imports go wrong

    QIF files carry no locale, so a date like 05/06/2026 is read month-first — March-style order, the same convention Quicken used — unless one of the numbers is over 12, in which case the data settles it. In CSV the date order is yours to set: the wizard's Date format dropdown does the work, and the preview shows the parsed date on every row before you commit, so a swapped day and month is visible as a weird-looking date rather than a silently wrong one. Watch the first row of any preview; if it looks like last month instead of this month, change the format and preview again.

  6. RBC Royal Bank

    Where: sign in, open the account, and look for a Download account history control on the account activity page — credit cards use the same control from the card's activity view. Format: RBC offers CSV as well as QFX; take the QFX when it is there. Quirk: RBC's CSV can split money into separate withdrawal and deposit columns, so choose Debit & Credit in the mapping wizard instead of a single amount — the sign then takes care of itself.

  7. TD Canada Trust (EasyWeb)

    Where: Accounts, open the account, then Download or Export from the account activity list. Format: QFX for chequing, savings and most cards, CSV everywhere. Quirk: card exports sometimes list every charge as a positive number; the Credits positive switch in the mapping wizard flips the whole file to the right sign in one click.

  8. BMO (Bank of Montreal)

    Where: Accounts, open the account, then Download from the account activity page. Format: CSV and QFX. Quirk: BMO CSVs tend to leave the description column carrying reference text alongside the payee; the preview shows it verbatim, and you can clean any row up after you commit rather than editing the export.

  9. Scotiabank

    Where: Accounts, then Account history, then Download. Format: CSV and QFX. Quirk: Scotiabank's site shows dates one way while some exports write them another — set Date format in the wizard to match the file itself, not the page you downloaded it from, and confirm on the preview's first row.

  10. Tangerine

    Where: Accounts, open the account, then look for Download under Recent activity. Format: CSV and QFX. Quirk: Tangerine's Chequing and Savings exports are straightforward; credit-card activity exports separately, so download the card statement rather than mixing the two into one file.

  11. Wealthsimple

    Where: the web app (the phone app does not export), open the account, then use the download control on its Transactions list. Format: CSV. Quirk: investment activity is a different file from Cash activity. Investment trades belong on the Import mode switch set to Investment trades, where the activity columns, symbol and quantity are read; bank-style CSVs go through the normal path.

  12. EQ Bank

    Where: open the account in online banking and look for a Download or Export control. Format: CSV when offered. Known gap: EQ Bank has been one of the few Canadian banks whose portal only publishes PDF statements, which this importer does not read — if your account shows no CSV or QFX option, there is no file to import yet and the statement cannot be converted. Everything else in these guides applies the moment an export appears.

  13. Rogers Bank

    Where: sign in to the card account and look for Download under account activity or statements. Format: CSV for card activity. Quirk: Rogers Bank is credit-card only, so there is never a chequing file to worry about; charges and refunds share one signed amount column, and refunds come through positive.

  14. MBNA

    Where: sign in, open the card account, then Download from the account history or statements area. Format: CSV and QFX. Quirk: MBNA runs on TD's platform, so the layout follows EasyWeb — the same Credits positive switch applies if charges arrive unsigned.

  15. Credit unions (Desjardins, Vancity, Coast Capital, Meridian, and the rest)

    Where: every credit union runs one of a handful of online-banking platforms, and they all expose a download on the account activity page — the label is usually Download, Export or Save as. Format: CSV is universal; OFX or QFX is offered on most platforms but not all. Quirk: because the platform is shared across unions, the mapping you set up for one institution usually carries over to another on the same system, so a second credit union often needs no setup at all.

  16. When a file will not import

    The error names the exact reason rather than failing silently: an unrecognized file means the export is not one of the three formats; a parse error names the record that could not be read (a missing date or amount stops the file instead of dropping the row); a missing mapping means the CSV has no saved column map yet, and the wizard opens so you can set one. Nothing partially imports — a rejected file leaves the database exactly as it was.
